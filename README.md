# 별지기 · STARWATCH

조선 관상감 천문관이 되어 하늘을 읽는 교실용 천문 게임.
하늘을 정확히 읽으면 승진, 틀리면 곤장!

## 배우는 내용

- 황도 12궁과 태양의 연주 운동 (지구의 공전)
- 계절·시각·방위에 따라 보이는 별자리 (지구의 자전과 공전)
- 달의 위상 변화, 음력 날짜와 시각에 따른 달의 모양과 위치
- 일식과 월식의 원리, 가려지는 방향, 관측 가능한 지역

## 모드

| 모드 | 설명 |
|---|---|
| 이야기 모드 | 혼자서 봄·여름·가을·겨울 밤 근무를 거쳐 마지막 일식 예보(구식례)까지. 곤장 3대면 파직 |
| 과거 시험 (교실 대결) | 선생님이 방(4자리 코드)을 열고, 학생들이 각자 기기에서 같은 문제를 푼다. 선생님 화면에 실시간 순위 |
| 천문대 — 자유 관측 | 날짜·시각·음력을 마음대로 바꾸며 하늘과 혼천의(지구·달 모형)를 본다. 설명용으로 좋다 |
| 별자리 도감 | 맞힌 별자리 22개를 수집 |

## 임무 종류

1. **망원경 조준** — 이름표 없는 밤하늘에서 별자리를 모양으로 찾기
2. **구름 낀 밤** — 주어진 날짜·시각·방위에 떠 있는 별자리 맞히기
3. **행차 시각** — 별자리가 남중하는 시각 맞히기
4. **상소·밀서 감정** — 천문 보고가 참인지 거짓인지 도장 찍기
5. **달 예보** — 음력 날짜와 시각으로 달의 모양과 위치 맞히기
6. **황도 12궁** — 지구를 궤도에 놓고, 한밤중 남쪽 별자리 맞히기
7. **일식·월식** — 달을 제자리에 놓고, 가려지는 방향 맞히기

막힐 때는 화면 위의 **혼천의** 단추를 눌러 지구(날짜)·관측자(시각)·달(음력)을 직접 돌려 볼 수 있다.

## 계산 기준

- 관측지는 한양(북위 37.5°), 시각은 태양시(정오에 태양 남중)
- 별은 실제 적경·적위, 태양은 하루 약 1°씩 황도를 이동
- 황도 12궁은 교과서 그림처럼 "그 달 초에 태양이 지나는 별자리"
  (4월 물고기 · 5월 양 · 6월 황소 · 7월 쌍둥이 · 8월 게 · 9월 사자 · 10월 처녀 · 11월 천칭 · 12월 전갈 · 1월 궁수 · 2월 염소 · 3월 물병)
- 달은 음력 1일 삭 · 8일 상현 · 15일 망 · 22일 하현으로 단순화

## 멀티플레이 방식

자체 서버 없이 공개 MQTT 중계 서버 3곳(EMQX, HiveMQ, Mosquitto)을 동시에 쓴다.
학생 기기는 같은 시드로 같은 문제를 만들어 풀고 점수만 보낸다.
